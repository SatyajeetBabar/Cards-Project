# Job Cards UI

A modern job listing cards project built with React.  
This project displays different job opportunities with details like company name, role, salary, job type, and location in a clean card-based layout.

## Features

- Responsive job cards UI
- Dynamic data rendering using APIs
- Axios for API requests
- Clean and modern design
- Built with reusable React components

## Tech Stack

- React
- JavaScript
- Axios
- CSS

## Preview

Job cards include:
- Company name
- Job role
- Salary
- Full-time / Part-time status
- Location
